# jaygriff.com, version 2

This is an old version of my website, kept running at **[v2.jaygriff.com](https://v2.jaygriff.com)**. The current site is **[jaygriff.com](https://jaygriff.com)**.

From January to March 2026, where I published my software development work and some personal stuff too. Written entirely in TypeScript using React, Next.js 16 and Emotion.

To learn more about it, browse the meta docs on the site itself, starting at [v2.jaygriff.com/about-this-site](https://v2.jaygriff.com/about-this-site).

## Running it

```bash
npm install
npm run dev
```
